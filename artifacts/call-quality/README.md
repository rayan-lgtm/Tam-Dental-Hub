# وكيل جودة الخدمة — تام دنتال

وكيل ذكي يحلل يومياً عينات من **المكالمات (اتصالنا)** و**محادثات الشات (respond.io)** لكل موظفة، ويقيّمها وفق معايير مراكز الاتصال العالمية ومعايير الضيافة الفاخرة، ويعرض النتائج في لوحة متابعة عربية.

**الهدف:** رفع مستوى الخدمة والضيافة في تام دنتال عبر متابعة يومية وتدريب مبني على أمثلة حقيقية.

---

## ماذا يقدم

| | |
|---|---|
| **تقييم كل محادثة** | 10 معايير (1-5) ← تقييم شامل من 100، الأمور الممتازة، المشكلات في الردود مع اقتباس، الصياغة المثالية المقترحة، نصيحة للغد، نتيجة المحادثة (حجز/فرصة ضائعة…)، انطباع المراجع |
| **لكل موظفة** | تقييم شامل + مقسّم (مكالمات / شات)، تطور يومي خلال الشهر، أقوى نقطة وأولوية التطوير، المشكلات المتكررة، خطة تدريب |
| **للفريق** | ترتيب الموظفات، اتجاه الأداء مقابل الهدف (85)، أولويات التدريب للفريق، الأخطاء الحرجة، نسبة الحجز، أسوأ وأفضل المحادثات للمراجعة والتدريب |

## المعايير

مبنية على: COPC CX Standard، ISO 18295، أبحاث الحل من أول تواصل (SQM)، معايير الضيافة (Forbes Travel Guide / Ritz-Carlton)، وتجربة المريض (Press Ganey).

| المعيار | وزن المكالمة | وزن الشات |
|---|---|---|
| الافتتاحية والترحيب | 8 | 8 |
| الضيافة والتعاطف | 15 | 13 |
| فهم الاحتياج | 12 | 12 |
| المعرفة ودقة المعلومة | 13 | 14 |
| تقديم الحل والحجز | 15 | 15 |
| وضوح التواصل واللغة | 10 | 12 |
| سرعة الاستجابة وإدارة الوقت | 6 | 8 |
| الملكية والمتابعة | 8 | 6 |
| الختام | 8 | 7 |
| الالتزام والخصوصية | 5 | 5 |

**أخطاء حرجة** (تحدّ التقييم عند 40): أسلوب غير محترم، نصيحة طبية خارج الصلاحية، مشاركة بيانات دون تحقق، معلومة خاطئة جوهرية، ترك المراجع دون حل.

التقييم الشامل يُحسب برمجياً من درجات المعايير والأوزان (وليس من النموذج)، لضمان الثبات والعدالة بين الموظفات. المعايير قابلة للتعديل في `artifacts/api-server/src/qa/rubric.ts`.

## كيف يعمل

```
respond.io (شات) ─┐
                  ├─► POST /api/qa/ingest ─► قاعدة البيانات (pending)
اتصالنا (مكالمات) ─┘        (كل المحادثات أو جزء منها)
                                   │
          يومياً 11:30 م ─► POST /api/qa/jobs/daily
                                   │  عينة 3-5 لكل موظفة لكل قناة
                                   │  (الأطول + الأقصر + عشوائي)
                                   ▼
                   تفريغ صوتي للمكالمات (إن لزم) ─► Claude ─► تقييم
                                   ▼
                          لوحة المتابعة /qa/
```

### الربط لاحقاً

الربط مصمم بحيث يكفي أي أداة (Zapier / n8n / Make أو سكربت) أن ترسل المحادثات إلى نقطة واحدة:

```http
POST /api/qa/ingest
x-qa-key: <QA_INGEST_KEY>
Content-Type: application/json

{
  "items": [
    {
      "channel": "chat",                 // chat | call
      "source": "respond_io",            // respond_io | ittisalna | manual
      "externalId": "conv_12345",        // يمنع التكرار
      "agentRespondIoId": "u-77",        // أو agentExt (تحويلة اتصالنا) أو agentName أو agentId
      "occurredAt": "2026-10-31T14:20:00+03:00",
      "customer": "عبدالله",
      "transcript": "الموظفة: ...\nالمراجع: ..."
    },
    {
      "channel": "call",
      "source": "ittisalna",
      "externalId": "call_888",
      "agentExt": "201",
      "durationSec": 245,
      "recordingUrl": "https://.../call_888.mp3"   // يُفرّغ تلقائياً عند التقييم
    }
  ]
}
```

- **respond.io:** ربط معرّف كل موظفة في الإعدادات، ثم إرسال نص المحادثة (رسائل الموظفة والمراجع مرتبة) عند إغلاق المحادثة (webhook) أو دفعة يومية.
- **اتصالنا:** ربط رقم التحويلة لكل موظفة، وإرسال رابط التسجيل. التفريغ الصوتي يتم عبر ElevenLabs Scribe (يدعم اللهجة السعودية) فقط للمكالمات التي تقع في العينة، لتقليل التكلفة.
- **الجدولة اليومية:** أي cron خارجي (Replit Scheduled Deployment أو cron-job.org أو Zapier Schedule) يستدعي:
  `POST /api/qa/jobs/daily` مع `x-qa-key: <QA_INGEST_KEY>` (بدون body = اليوم الحالي، أو `{"date":"2026-10-31"}`).

إلى أن يكتمل الربط: يمكن لصق أي محادثة من صفحة **«تقييم محادثة»** وتقييمها فوراً.

## الإعداد

متغيرات البيئة (Secrets) لخادم الـ API:

| المتغير | الوصف |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude — **مطلوب للتقييم** |
| `QA_ADMIN_KEY` | مفتاح دخول لوحة المتابعة |
| `QA_INGEST_KEY` | مفتاح للأنظمة الخارجية (ingest + الجدولة اليومية) فقط |
| `ELEVENLABS_API_KEY` | اختياري — لتفريغ تسجيلات المكالمات |
| `QA_MODEL` | اختياري — الافتراضي `claude-opus-5-5` |
| `QA_EFFORT` | اختياري — `low` / `medium` (افتراضي) / `high` |
| `QA_SAMPLES_PER_DAY` | اختياري — 3 إلى 5 (افتراضي 4) لكل موظفة لكل قناة |

بعد النشر:

```bash
pnpm --filter @workspace/db run push   # إنشاء جداول qa_*
```

ثم افتح `/qa/`، أضف الموظفات من **الإعدادات**، ويمكن تحميل **بيانات تجريبية** لاستعراض اللوحة (تُحذف بزر واحد).

### التكلفة التقريبية

كل تقييم ≈ 5 آلاف رمز إدخال (معظمها معايير مخزّنة مؤقتاً) + 1.5-2 ألف رمز إخراج. لـ 10 موظفات × قناتين × 4 عينات = 80 تقييم يومياً ≈ 3-5 دولار يومياً على Claude Opus 5.5.
